# 📱 勵志語與知識靈感卡片 App (PWA)

一個極簡、優雅且老花友善的個人勵志金句與讀書筆記抽卡 App。

> **💡 設計理念：**  
> 這不是一個用來死記硬背的備考工具（如 Anki），而是一個**無壓力、隨手翻閱、記錄體悟的私人知識與靈感靈魂庫**。透過隨機與洗牌抽卡，讓每次翻牌都成為一次意外的收穫（Serendipity）。

---

## ✨ 主要特色

- 🃏 **雙抽卡模式：**
  - **🎲 隨機模式：** 隨機抽選，享受不期而遇的靈感。
  - **🃏 洗牌模式：** 自動洗牌且**不重複抽卡**，看完全部卡片後自動開啟下一輪。
- ✍️ **心得筆記與歷史：** 每張卡片皆可撰寫個人的閱讀感悟，支援條列式編輯與歷史紀錄檢視。
- 🔊 **連續語音朗讀：** 內建 Web Speech 語音朗讀，可自動切換播放下一張，支援自訂語速（1.0x~2.0x）與聲音角色（男聲/女聲/童音等）。
- 🌙 **智慧沉睡機制：** 點擊「不喜歡」的卡片會移入沉睡庫，3 個月後自動釋放；累積滿 5 次則正式刪除。
- 🔍 **動態分類與全文搜尋：** 選單即時顯示各分類/標籤的卡片總數量，支援內文、來源、標籤與心得全文關鍵字搜尋。
- 🛡️ **100% 隱私與離線可用：** 所有資料完全儲存於手機/電腦在地端（`localStorage`），無伺服器隱私風險，斷網亦可順暢使用。
- 📥 **智慧備份與合併：** 支援一鍵匯出 JSON 與 UTF-8 TXT 備份檔。匯入新 JSON 時會執行智慧合併，**自動完整保留您原有的心得與按讚紀錄**。

## 📲 安裝方式 (新增至手機主畫面)

不用透過 App Store 或 Google Play，只需利用瀏覽器「新增至主畫面」，即可享有全螢幕、無網址列的獨立 App 體驗：

### 🍎 iOS (iPhone / iPad)
1. 使用 **Safari 瀏覽器** 開啟 App 網頁。
2. 點擊螢幕下方中間的 **「分享」圖示** ($\uparrow$)。
3. 向下滑動點選 **「新增至主畫面」**。

### 🤖 Android (安卓)
1. 使用 **Chrome 瀏覽器** 開啟 App 網頁。
2. 點擊右上角的 **「三點選單」** (`⋮`)。
3. 點選 **「新增至主畫面」** 或 **「安裝應用程式」**。

## 🛠️ 技術架構

- **前端技術：** HTML5, CSS3 (CSS Variables / Flexbox / Grid), JavaScript (ES6+)
- **資料儲存：** LocalStorage API (Web Storage)
- **語音合成：** Web Speech Synthesis API
- **檔案處裡：** Blob API, JSON parsing with BOM handling (UTF-8)
