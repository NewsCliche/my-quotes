# 📱 勵志語與知識卡片 App (MotivCards)

一個專為個人成長、書摘記錄與習慣養成設計的 PWA 卡片式 Web App。支援大字體老花友善視覺、隨機/洗牌抽卡、語音連續朗讀、心得筆記管理，以及 CSV / JSON 試算表批次匯入匯出功能。

---

## ✨ 核心特色功能

- 🃏 **卡片式抽卡體驗：** 支援「🎲 隨機模式」與「🃏 洗牌不重複模式」，支援左右滑動切換卡片。
- 🔊 **語音連續朗讀 (TTS)：** 自動依序朗讀卡片內文與來源，可自由微調 1.0x ~ 2.0x 語速。
- 💬 **閱讀心得日誌：** 每一張卡片皆可寫下個人體悟與註解，自動記錄時間戳記。
- 📊 **Excel / 試算表批次管理：** 支援一鍵匯出/匯入 CSV 格式，方便在電腦上大批輸入與整理書摘。
- 💾 **全系統 JSON 備份：** 換手機或跨裝置時，可 100% 完整還原所有卡片、心得與喜愛紀錄。
- 🌙 **沉睡庫與篩選機制：** 按讚加入喜愛庫，不喜歡的卡片會移入沉睡庫（可隨時復原）。

---

## ⚠️ 語音朗讀功能重要使用須知 (請特別注意)

當您開啟 **`🔊 語音連續朗讀`** 功能時，請注意以下手機系統限制：

> 🚨 **【重要】朗讀時請勿關閉網頁、切換 App 或關閉螢幕！**
> 
> * **為什麼離開頁面聲音會中斷？**  
>   手機作業系統（Android / iOS）與 Chrome 瀏覽器為了節省電量與記憶體，當您按下 Home 鍵回到桌面、切換至其他 App（如 LINE）或按下電源鍵鎖屏時，系統會在 **1~3 秒內強制凍結背景網頁的 JavaScript 運作**。
> 
> * **如何維持正常連續朗讀？**  
>   1. **請保持 App 網頁畫面開啟**（建議將手機螢幕休眠時間調長，或放在車架/桌上觀看）。
>   2. 若不小心切換到其他 App 導致聲音中斷，**重新點回卡片 App 視窗**，程式會自動無縫喚醒並接續朗讀。

## 📊 CSV 試算表批次編輯與匯入指南

若您想在電腦上使用 **Excel** 或 **Google 試算表** 批次寫入大量語錄並匯入 App，請遵循以下格式：

### 1. CSV 欄位順序（第一行為標頭，請勿刪除）
| A 欄 (語錄內文) | B 欄 (來源/作者) | C 欄 (標籤) | D 欄 (新增日期) |
| :--- | :--- | :--- | :--- |
| 我們重複做的事情，造就了我們 | 亞里斯多德 | 習慣養成; 心靈成長 | 2026-08-06 |

### 2. Excel 存檔注意事項
在 Excel 編輯完畢另存新檔時，**請務必選擇：`CSV UTF-8 (逗號分隔) (*.csv)`** 格式，這樣 App 匯入時才不會產生中文亂碼。

## 📱 手機桌面安裝教學 (PWA)

- **Android (Chrome)：** 點擊右上角 `⋮` 選單 ➔ 點選 **「安裝並建立捷徑」**
- **iPhone (Safari)：** 點擊下方「分享」圖示 ➔ 點選 **「新增至主畫面」**

---

## ⚙️ 語音角色變更說明 (Android)

App 預設調用手機系統的預設語音包。若您想更換男聲/女聲或下載道地的國語發音，請至手機系統設定：

> 📱 **路徑：** `設定` ➔ `更多設定` ➔ `語言與輸入法` ➔ `文字轉語音輸出` ➔ `偏好的引擎` (點選右側帶圈圈的 `>`) ➔ `安裝語音資料` 進行切換或下載。
